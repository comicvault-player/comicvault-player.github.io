1. 対象 / Scope

ComicVault Player（本アプリ）は、ユーザーがアクセス権を持つローカルまたはクラウドストレージの画像・漫画・動画を閲覧し、対応するファイルを管理するためのアプリです。

ComicVault Player is designed to let users view and manage media in local and connected cloud storage they are authorized to access.

2. Google Driveからアクセスする情報 / Data accessed

ユーザーがGoogle Drive連携を認可した場合、許可された範囲内でファイル名、フォルダ階層、ファイルID、種類、サイズ、更新日時、必要なファイル内容および認可に必要なトークン等を取り扱う場合があります。実際のアクセス対象は承認されたOAuthスコープとユーザーの操作に依存します。

When authorized, the app may process filenames, folder structures, identifiers, file types, sizes, modification times, contents needed for operations, and authorization tokens, subject to the granted OAuth scopes and user actions.

3. 使用目的 / Purposes

データは、ファイル・フォルダの一覧表示、メディアの閲覧、ユーザーが指定したアップロード・書き込み・移動・削除・フォルダ作成、および暗号化データの保存と復号閲覧のために使用する設計です。利用者が指定しないファイルの変更や削除は行わないことを目標仕様としています。

Data is intended for listing and viewing media and user-directed uploads, writes, moves, deletions, folder creation, encrypted storage, and decrypted viewing. The design does not intend to modify or delete files without the user's direction.

4. 保存、処理とセキュリティ / Storage, processing and security

表示や操作に必要な一時ファイル、サムネイル、設定、認可情報が端末上に保存される場合があります。暗号化や復号の処理方法、認可トークンの保存保護、キャッシュ保持期間、アプリ削除時の扱い、サーバーへの送信の有無は、公開するアプリの実装を確認したうえで確定します。

Temporary files, thumbnails, settings, and authentication information may be stored on the device. Encryption/decryption processing, token protection, retention periods, deletion behavior, and any server transmission must be verified against the shipping implementation.

暗号化パスワードの取り扱い / Encryption passwords

暗号化・復号のために入力するパスワードの保存有無、保存場所、端末上の保護方法は、公開するアプリの実装に応じて明記します。パスワードを忘れると暗号化データを復号できなくなるおそれがあるため、利用者は自身で安全に管理してください。

Whether encryption passwords are stored, where they are stored, and how they are protected must be disclosed based on the released app. Losing a password may make encrypted data inaccessible; users should retain it securely.

元ファイルの置き換え / Original file replacement

アプリは、ユーザーの明示的な暗号化操作により、元ファイルを暗号化ファイルに置き換える設計です。暗号化ファイルの書き込みと検証が成功する前に元ファイルを削除しない設計とし、失敗時には元ファイルを保持します。これは目標仕様であり、公開前に実装と一致することを検証します。復号した閲覧データの一時保存・削除方法も実装確認後に確定します。

The intended workflow replaces an original file with an encrypted file at the user’s express request. The original should not be deleted until the encrypted output has been written and verified; failed operations should retain the original. These are intended safeguards that must be validated in the shipping app. Handling of temporarily decrypted data will also be finalized after implementation review.

5. 共有と第三者サービス / Sharing and third-party services

ユーザーの指示したファイル操作に必要な範囲で、Google Driveなどの接続先サービスと通信します。分析SDK、クラッシュ報告、外部認証サーバー等へのデータ送信が存在する場合は、公開前に送信先・目的・対象データを追加で開示する必要があります。Googleユーザーデータを広告ターゲティング目的で販売しない方針です。

The app communicates with selected storage providers to perform user-requested operations. Any analytics, crash reporting, or third-party authorization service must be identified and accurately disclosed before release. Google user data is not intended for sale for ad targeting.

6. 取り消し、ファイル削除、問い合わせ / Revocation and deletion

Googleとの連携はGoogleアカウントの接続管理から解除できます。Google Drive上のファイルを削除する操作と、アプリ内キャッシュ・認可情報を削除する操作は別のものです。アプリ内データの具体的な消去方法は、実装確定後に明記します。お問い合わせはcomicvault.support.em@gmail.comまでご連絡ください。

Users may revoke access through Google Account connections. Deleting a Drive file is different from removing local caches or authorization data. Exact in-app data removal steps must be documented after implementation is verified. Contact: comicvault.support.em@gmail.com.

7. Google API Services User Data Policy

Google APIを通じて取得する情報は、適用されるGoogle API Services User Data Policy（Limited Use要件を含む）に従う方針です。実際の使用、共有、人による閲覧、保存について実装を確認して公開内容と一致させます。

The app is intended to comply with the Google API Services User Data Policy, including Limited Use requirements. Actual use, sharing, human access, and storage must match the released app and this policy.
